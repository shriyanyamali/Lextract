# Lextract - LDA 2026 workshop paper (LaTeX source)

Full paper (up to 10 pages) for the 9th Workshop on Legal Data Analysis (LDA 2026), held with JURIX 2026, Toulouse, 8 December 2026. The workshop specifies no template; the IOS Press / JURIX class is kept.

## Contents

- `paper.tex` - manuscript
- `paper.bib` - bibliography
- `IOS-Book-Article.cls`, `vancouver.bst` - IOS Press class and bibliography style
- `figures/` - figures of the earlier JURIX submission (not used in the current text; kept for reference)
- `paper.pdf` - compiled PDF
- `easychair_submission.txt` - title, abstract and keywords as plain text for the EasyChair form

## Compile

```bash
pdflatex paper.tex
bibtex paper
pdflatex paper.tex
pdflatex paper.tex
```

All numbers in the paper are regenerated by the commands in `../docs/EVALUATION.md`.
